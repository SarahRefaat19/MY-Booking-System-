A trusted and easy-to-use platform that connects people with home and professional service providers quickly and securely - making booking any human service (plumbing, electrical, cleaning, maintenance) happen in minutes with guaranteed quality and transparency in pricing and ratings.

# Tech Stach

Backend: [ASP.NET](http://asp.net/) Core Web API
Architecture: Clean Architecture
Database: SQL Server
ORM: EF Core
Auth: JWT
# Roles

- Admin
- Customers
- Service Provider

# Features

- User authentication (login/signup for customers & providers)
- Service catalog & search/filter
- Provider profiles

## Public Features:

- Booking system
- Real-time notifications
- In-app chat (customer ↔ provider)
- Payment gateway integration
- Rating & review system
- Booking history & tracking
- Service status updates

## **For Customers:**

- Save favorite providers
- Multiple addresses management
- Booking cancellation/rescheduling
- Support/help center

## **For Providers:**

- Availability calendar management
- Earnings dashboard
- Service management
- Accept/decline bookings
- Withdrawal requests

## **For Admin:**

- User management (approve/suspend accounts)
- Provider verification system
- Reports & analytics dashboard
- Handle disputes/complaints
- Commission management
